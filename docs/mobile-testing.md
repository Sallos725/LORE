# 실기기 검증 (아직 미실행)

Chromium/WebKit 자동 UI 테스트는 iPhone Safari의 메모리 결과를 대신하지 않는다.

1. PocketRisu commit, 기기/iOS, 대화 길이·이미지 수, 위키 문서 수, 활성 플러그인을 기록한다.
2. 같은 데이터로 PocketRisu 단독 / Lite / Full을 비교한다.
3. 긴 채팅에서 위키 열기·검색·수정·닫기를 30회 반복한다. Full은 20개씩 목록과 선택한 본문만 가져오는지 네트워크 전송량을 확인한다.
4. 화면 잠금·탭 닫기·재접속 후 Full에 이미 수락된 작업이 조회되는지 확인한다. 브라우저가 보내지 못한 이벤트의 복구는 현재 미지원이다.
5. 서버 중단·잘못된 token·저장 revision 충돌 시 위키 상태와 일반 채팅을 확인한다.
6. 측정 가능한 메모리 peak·전송량, Safari reload/OOM 횟수, 평균 작업 시간을 남긴다. Lite 128개 상한과 최대 본문도 시험한다.
7. 자동 사실 추출 도입 전 기억 품질을 주장하지 않는다. 향후 인물/관계/시점/비밀·분기 누출을 별도 합성 시나리오로 평가한다.
