# 공개 준비도 점검 — 2026-09-21

대상: `v0.1.0-alpha.3` (`193254e11e9d68d6b5fb2441a5b194275334427a`)의 런타임과 현재 main의 배포 설정.

**판정: 개발자에게 소스를 공개하고 피드백을 받는 알파 프로젝트로는 공개 가능하다. 일반 사용자에게 완성된 장기 기억 플러그인으로 권하기에는 아직 부족하다.** 체험 배포 범위를 넓히기 전에 아래 재현된 문제 2개를 수정하고 실제 PocketRisu 설치 검증을 완료해야 한다. 2026-09-21 확인 시 GitHub 저장소는 PUBLIC이며, 이 점검에서 공개 범위를 변경하지 않았다.

## 재현한 문제

### P2 — 설정되지 않은 작업 뒤의 정상 작업이 실행되지 않음

근거: [server/memory.mjs:30](https://github.com/Sallos725/LORE/blob/193254e11e9d68d6b5fb2441a5b194275334427a/server/memory.mjs#L30).

worker는 queued 작업을 앞에서 128개 읽은 후, 모델을 사용할 수 있는 작업을 고른다. 앞의 128개 모두 모델 미설정이면 뒤에 있는 정상 작업은 선택되지 않는다. UI에서 특정 범위의 모델만 설정하거나 서버 재시작 후 다른 범위의 키를 아직 입력하지 않은 상황에서 발생할 수 있다.

합성 SQLite에서 A 범위에 모델 미설정 작업 128개, B 범위에 설정된 작업 1개를 넣고 같은 선택 함수를 실행했다.

```json
{"queued":129,"worked":false,"calls":0,"readyJobState":"queued"}
```

예상: A는 설정을 기다리되 B의 작업은 처리한다. 수정 방향은 실행 가능한 범위를 기준으로 쿼리하거나, 메모리 상한을 유지하는 iterator로 후보를 계속 찾는 것이다. 미설정 범위가 다른 범위를 막지 않는 회귀 검증이 필요하다.

### P2 — 시간 초과 후 실제 요청과 다른 성공 상태 표시

근거: [plugin/runtime.mjs:55](https://github.com/Sallos725/LORE/blob/193254e11e9d68d6b5fb2441a5b194275334427a/plugin/runtime.mjs#L55), [상태 갱신:63](https://github.com/Sallos725/LORE/blob/193254e11e9d68d6b5fb2441a5b194275334427a/plugin/runtime.mjs#L63).

finalBody는 2.5초 뒤 원래 요청을 반환하지만, 이미 시작한 비동기 조회는 계속 실행된다. 같은 epoch에서 늦게 완료되면 주입된 요청이 실제로 반환되지 않았어도 성공 상태로 덮어쓴다.

유효한 예산·범위·cursor를 제공하고 capture를 2.7초 지연시킨 합성 호출로 확인했다.

```json
{
  "requestUnchanged":true,
  "immediateStatus":"기억 조회 시간 초과 · 일반 채팅을 계속합니다. · 기억 없이 채팅을 계속합니다.",
  "lateStatus":"기억 주입 완료 · 보수적 예산 추정 통과"
}
```

예상: 이 요청은 계속 시간 초과/주입 생략으로 표시한다. 요청별 만료 여부를 검사하고, 실제 반환한 요청의 결과만 상태에 반영해야 한다. 시간 초과·중지·뒤따르는 요청과의 경쟁을 회귀 검증해야 한다.

위 두 문제는 이번 점검에서 **재현·기록한 상태이며 alpha.3 런타임에는 아직 수정하지 않았다.** latest도 같은 alpha.3 이미지다.

## 공개 범위를 넓히기 위한 순서

1. 재현한 작업 선택·늦은 상태 표시 문제를 수정하고 새 버전을 발행한다.
2. 수정하지 않은 실제 PocketRisu에 Lite/Full을 설치해 로그인·권한·채팅 수정/삭제/분기·주입·재시작까지 확인한다.
3. 실제 iPhone에서 긴 채팅·큰 위키·이미지·잠금/재접속을 비교 측정한다.
4. 개인정보 없는 서사 평가 세트와 선택한 실제 LLM으로 근거·모순·별칭·공개 범위 품질을 평가한다.
5. 설치 안내만 보고 진행하는 사용자 테스트, 설정 복구·백업/이동을 보완한 뒤 일반 사용자용 베타 범위를 정한다.

현재 소개 문구는 “PocketRisu용 위키 기반 장기 기억 **개발 알파** — 제한된 테스트 참여자 대상”이 적절하다. “완성품”, “모든 공급자에서 기억 주입”, “Safari OOM 해결”을 주장할 근거는 아직 없다.
