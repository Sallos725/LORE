# 공개 준비도 — alpha.4

소스와 설치 파일을 공개하고 테스트 참여자를 받는 상태로 제공한다. “iPhone Safari OOM 해결”이나 모든 모델·모든 입력에서 완성된 장기 기억을 보장하는 안정판으로 소개하지 않는다. 아래 수정·시험 결과와 아직 확인하지 못한 범위를 구분한다.

## 수정한 문제

- 별도 scope token과 수동 캐릭터/채팅 ID 설정을 제거했다. 기존 PocketRisu 로그인으로 인증하고 서버가 저장된 안정 ID를 확인한다.
- 같은 봇 카드의 여러 채팅을 ID별 위키로 자동 분리한다. 같은 배열 위치에 새로운 채팅이 생겨도 구분하며 이전 채팅으로 돌아가면 기존 위키를 쓴다.
- 앞의 128개 미설정 작업이 뒤의 정상 추출을 막던 큐 정체를 수정했다. 제한된 큐를 iterator로 확인한다.
- 주입 시간이 초과된 뒤 늦은 처리가 “주입 완료”로 바꾸던 상태 오류를 수정했다. 종료·다음 요청으로 인한 무효화도 검사한다.
- 원본 호스트의 실제 getter가 숫자 인덱스를 반환하는 호환성 결함을 설치 시험에서 발견해 수정했다. 전체 DB/캐릭터 복사 없이 기존 메타데이터 API로 안정 ID를 찾는다.
- 공통 beforeRequest 주입을 기본으로 추가했다. 모델 프리셋도 이 훅을 사용한다. 기존 OpenAI 최종 body 검사는 별도 선택으로 유지한다.
- Full의 추출 설정은 재시작 뒤에도 유지한다. Lite는 비밀 값을 제외한 설정 기억과 문서·이력·원문·작업 전체 백업/복원을 제공한다.
- 최초 대화의 예산 권한 창이 조회 시간을 소모하지 않도록 자동 기억 시작 때 먼저 권한을 확인한다.

- 실제 호스트의 동일 저장 재전송이 revision 충돌로 표시되는 문제를 고쳤다. 별도 편집 충돌 검사는 유지한다.
- 현재 질문에 최근 두 대화의 맥락을 더해 이름 없는 후속 질문에서도 관련 위키를 검색·주입한다.

## 검증 근거

| 항목 | 결과 |
|---|---|
| 자동 엔진 검증 | Node 53개: 원문·수정·삭제·분기·수동 교정·멱등성·예산·큐·인증·범위·복원·공급자 계약 |
| 배포 검증 | Python 8개, 패키지 실제 설치/실행, 읽기 전용 컨테이너·독립 볼륨의 재시작 보존 |
| Chromium/WebKit | Lite/Full UI, 계층·별칭·링크·수정·백업/복원·설정 기억·자동 추출/주입·반복 열기/닫기 |
| 실제 PocketRisu | 고정된 공식 원본 이미지에서 JS 설치·로그인 자동 연결·위키 수정·원문 수집·독립 LLM·Gemini 요청 주입 확인. 재실행 절차는 tests/host.mjs |
| 실제 LLM | 기존 Ollama의 gpt-oss:120b-cloud에 합성 사례 3건, 보완 후 모두 기준 통과. 결과는 memory-evaluation.json |
| latest | 릴리스 파일 공개 성공 후 동일 amd64/arm64 이미지 index를 latest로 연결하는 Actions 구현 |

실제 LLM 초기 시험에서는 원문 밖 지리 지식 추가와 지시문 재인용을 발견했다. 닫힌 서사 세계와 발언/농담/계획을 구분하는 추출 지침으로 보완했다. 이후 한 시험의 정확하지 않은 인용은 검증기가 거부했다. 최종 같은 3개 사례는 첫 시도에 검증을 통과했다. 사례는 현재/과거/계획·별칭, 인물별 비밀, 원문 속 지시문이다. 이 작은 평가가 임의의 긴 서사에서 모든 문장의 의미를 증명하지는 않는다. 추출 문서에는 검토 필요 상태를 유지한다.

## 남은 검증과 명시적 지원 범위

- **실제 iPhone/iOS Safari 장시간 시험은 미실행이다.** 이 개발 환경에서는 화면 잠금·백그라운드·기기 OOM을 측정할 수 없다. docs/mobile-testing.md의 실기기 비교가 필요하다. 데스크톱 WebKit 결과로 대신했다고 표현하지 않는다.
- 이미지·도구가 포함된 프롬프트는 주입하지 않는다. 전체 예산은 UTF-8 기반 추정이며 공통 훅 이후 다른 플러그인·트리거의 변경과 공급자 내부 계산은 통제하지 않는다.
- 서버에 보내기 전에 탭을 닫은 새 원문을 자동 발견하는 outbox는 없다. 수락한 Full 작업의 지속은 검증하지만 아직 보내지 못한 이벤트의 지속을 주장하지 않는다.
- 실제 호스트의 각 공급자·모델 프리셋 조합, 대규모 장기 서사, iPhone 설치 안내만 따르는 사용자 시험은 별도 범위다. 제한된 추출 API 프로토콜 테스트와 실제 Gemini 경로 검증을 모든 조합의 실측 결과로 일반화하지 않는다.

따라서 공개 설명은 **“PocketRisu를 수정하지 않는 채팅별 위키 기억 플러그인 — 공개 테스트 버전”**으로 한다. 공개된 저장소의 접근 범위는 이 작업에서 변경하지 않는다.
